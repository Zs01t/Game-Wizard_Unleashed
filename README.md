# Wizard Unleashed

## Overview
This is a real-time top-down dungeon crawler type of game made with WPF.

## Features
 - The game has enemies who can pathfind to the player and also dodge the incoming projectiles
 - It also has a simple level editor; after a new level is created it goes at the end of the level list, so it can be played immediately

## Controls

- **Arrow Keys**: Move the character left, right, up or down.
- **Spacebar**: Shoot projectile.
